# Presidio

Experiments with [Microsoft Presidio](https://github.com/microsoft/presidio) for detecting and anonymizing PII, including its limitations on non-English text.

## Setup

```bash
python3 -m venv presidio-env
source presidio-env/bin/activate
pip install -r requirements.txt
```

Then open `ms_presidio.ipynb` in Jupyter or VS Code and select the `presidio-env` kernel.
